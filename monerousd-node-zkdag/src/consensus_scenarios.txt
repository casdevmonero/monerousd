# MONEROUSD CONSENSUS SCENARIOS — the case library.
#
# Every case below is a class a GATE RUN found the expensive way: roughly fifteen minutes, a frozen
# binary and a machine freeze, for one bit of information. Written here they run in seconds, on every
# build, so a class that cost a day cannot come back unnoticed.
#
# GRAMMAR (one case per `name` block; `#` starts a comment):
#   name     <case-name>
#   parties  <n>                  how many nodes take part (default 2)
#   produce  <party> [count]      that party produces blocks; everyone else owes each one
#   deliver  <k>                  hand over the k-th owed block — OUT OF ORDER on purpose
#   drain                         hand over everything still owed
#   restart  <party>              export the checkpoint, start fresh, restore — a real restart
#   jump     <to> <from>          `to` adopts `from`'s certified bundle, the way a joiner does
#   burst    <k>                  hand over the next k owed blocks at once — a cascade
#   drop     <party>              lose one owed delivery to that party for good (only a parent ask can bring it)
#   receive  <party>              that party produces a block carrying a REAL note (bytes, never cover)
#   forget   <party>              that party forgets every idle record's bytes (they must regenerate)
#   tamper   <to> <from>          `to` is offered a TAMPERED bundle from `from` — must refuse, state untouched
#   forge-rows <party>            that party is paged forged rows — none may displace a claim, never stale
#   invalid  <party>              that party gossips a wrong-work block — everyone must reject it
#   replay   <to> <from>          `to` is re-sent the bundle it last adopted from `from` — nothing may move
#   spend    <party>              that party spends a real note it holds — a deletion its next block carries
#
# THE PROPERTIES, checked after every case (the drain emulates the mesh: parent asks, sidecar pages,
# roots runs): no honest block was ever refused; every party derives the same ordinal for every record,
# the same dense fold counter, the same spine root, the same unspent root and the same selected tip;
# every party still holds the genesis record at ordinal 0; every party is READY (no orphans, no stale
# spine, no sidecar gap, no missing record, serving); every real-note record is held byte for byte by
# every party at the same ordinal; every party gives the same present/absent verdict for every real
# note (digital cash); and the carry stays bounded by depth × width. An adversarial action
# (tamper, forge-rows, invalid, replay) carries its own verdict: the refusal must happen.
